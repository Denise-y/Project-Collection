# 迷宫搜索算法研究与可视化（Maze Search Algorithms）

一个基于 Python 的交互式迷宫求解系统，实现了五种经典搜索算法（BFS、DFS、UCS、Greedy、A*）并在随机生成的迷宫中进行可视化对比与性能评估。项目采用 Jupyter Notebook 形式，结合 Pygame 实时渲染搜索过程与最优路径。

## 项目概述

本项目通过构建 40×40 的随机迷宫环境，系统性地实现了问题建模、状态空间定义、搜索算法实现、可视化求解及跨算法性能对比分析。核心目标是在保证算法完备性与最优性的前提下，探索不同搜索策略在节点扩展数、路径成本与执行效率之间的权衡关系。

## 技术栈

- **语言**：Python 3
- **可视化**：Pygame（迷宫生成与路径渲染）
- **开发环境**：Jupyter Notebook（代码 + 报告一体化）
- **核心模块**：
  - `maze.py` — 迷宫网格生成与单元格管理（不可修改）
  - `searchCW.py` — 搜索框架与数据结构（不可修改）
  - `lab4` — 统计报告与柱状图可视化工具

## 核心功能

### 1. 迷宫环境建模
- 基于 `MazeGrid` 类生成 40×40 随机迷宫（种子 200）
- 通过 `Maze` 子类继承 `Mazetemp`，自定义 `actions(state)` 方法
- 状态表示为 `(row, col)` 坐标，动作空间为上下左右四方向移动
- **邻居有效性判定**：当前单元格与目标单元格之间无墙壁阻隔，且目标单元格未被访问

### 2. 五大搜索算法实现

| 算法 | 数据结构 | 特性 |
|------|----------|------|
| **BFS** (Breadth-First) | FIFO 队列 | 完备、最优（单位成本） |
| **DFS** (Depth-First) | LIFO 栈 | 不完备、非最优、节点扩展少 |
| **UCS** (Uniform-Cost) | 优先队列（路径成本） | 完备、最优（通用成本） |
| **Greedy** | 优先队列（启发式） | 不完备、非最优、效率高 |
| **A\*** | 优先队列（f = g + h） | 完备、最优、效率平衡 |

所有算法基于统一的树搜索框架实现，支持实时绘制：
- **已访问单元格**（搜索过程可视化）
- **解路径**（从起点到终点的最优/可行路径）

### 3. 迷宫求解可视化
- 起点 `(0, 0)`，终点 `(39, 39)`
- 调用任意搜索算法求解并在 Pygame 窗口中渲染
- 直观展示搜索树的探索范围与最终路径

### 4. 跨算法性能对比分析
在三种不同随机种子生成的迷宫场景中，对比五类算法的核心指标：

| 指标 | 说明 |
|------|------|
| 节点扩展数 | 搜索过程中访问的节点总量 |
| 目标测试数 | 执行目标检测的次数 |
| 总路径成本 | 解路径的累积代价 |
| 动作数 | 解路径包含的移动步数 |

使用 `report()` 与 `show_bar()` 方法生成统计报表与可视化图表。

### 5. 算法评估报告（200-300 词）
基于实验数据撰写分析报告，涵盖：
- **完备性与最优性**：BFS/UCS/A* 保证最短路径；DFS/Greedy 可能产生次优解
- **搜索效率**：DFS/Greedy 节点扩展少但牺牲最优性；A* 较 BFS 减少约 40% 节点扩展
- **实际应用建议**：A* 为迷宫问题的首选算法；Greedy 适用于实时性要求高的场景

### 6.  bonus：方向变换代价模型
- 自定义 `action_cost(s, a, s1)` 方法，使路径成本基于**方向变换次数**
- 重新评估五大算法在新代价模型下的表现
- 探索非均匀代价对搜索策略的影响

## 关键实验结论

| 算法 | 节点扩展 | 路径成本 | 适用场景 |
|------|----------|----------|----------|
| BFS | ~11,600 | 最优 | 小规模、解质量优先 |
| UCS | ~11,500 | 最优 | 通用代价环境 |
| DFS | ~780 | 次优（540） | 仅需可行解、快速响应 |
| Greedy | ~560 | 次优（280） | 实时启发式引导 |
| A* | ~7,000 | 最优 | **综合最优选择** |

> 数据基于 30×30 迷宫、三种随机种子的平均结果
