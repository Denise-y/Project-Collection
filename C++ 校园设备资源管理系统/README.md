# 校园设备资源管理系统（Campus Resource Management System）

一个基于 C++23 的面向对象命令行应用程序，为宁波诺丁汉大学（UNNC）设计，用于管理校园内四类设备（笔记本电脑、相机、投影仪、电动自行车）的借用、归还、查询与逾期罚款计算。项目严格遵循现代 C++ 最佳实践，涵盖多态继承、智能指针、STL 算法、Lambda 表达式与移动语义等核心特性。

## 项目概述

本项目实现了一个菜单驱动的校园设备资源管理系统，支持设备的增删改查、借用状态切换、逾期罚款自动计算以及按名称排序展示等功能。系统采用经典的面向对象设计模式，以抽象基类 `Resource` 定义统一接口，四种具体设备类型通过多态实现各自的借阅期限与罚款规则。所有资源对象由 `std::unique_ptr` 智能指针管理，彻底杜绝内存泄漏。

项目对输入验证和输出格式有极高要求：每一个提示符、空格、大小写都必须与规范完全一致，以通过自动化测试脚本的字符级比对。

## 技术栈

- **编程语言**：C++23
- **编译器**：G++ (csubuntu 服务器)
- **标准库**：STL（`<vector>`, `<algorithm>`, `<memory>`, `<iostream>`, `<iomanip>` 等）
- **内存管理**：`std::unique_ptr` + `std::make_unique`（零裸指针）
- **构建命令**：`g++ -std=c++23 campus.cpp -o campus`

## 核心功能

### 1. 设备类型与多态设计

系统管理四种设备，每种拥有独立的借阅期限和每日逾期罚款率：

| 设备类型 | 类名 | 最大借阅天数 | 逾期罚款 (CNY/天) |
|----------|------|-------------|-------------------|
| 笔记本电脑 | `Laptop` | 7 | 20.00 |
| 相机 | `Camera` | 3 | 15.00 |
| 投影仪 | `Projector` | 1 | 50.00 |
| 电动自行车 | `Ebike` | 1 | 30.00 |

**多态接口**（抽象基类 `Resource`）：
- `display()` — 纯虚函数，统一输出设备信息
- `maxBorrowDays()` — 返回该设备类型的最大借阅天数
- `penaltyPerDay()` — 返回该设备类型的每日逾期罚款率
- 虚析构函数 — 确保派生类对象通过基类指针正确释放

### 2. 资源标识与验证体系

资源 ID 采用严格格式：**1 个大写字母前缀 + 3 位数字**，共 4 字符：

| 设备类型 | 前缀 | 有效示例 |
|----------|------|----------|
| 笔记本电脑 | `L` | `L001`, `L042` |
| 相机 | `C` | `C001`, `C099` |
| 投影仪 | `P` | `P001`, `P010` |
| 电动自行车 | `E` | `E001`, `E007` |

**输入验证规则**：
- ID 全局唯一，重复添加无效
- 名称与所有者必须为单个单词，匹配正则 `[A-Za-z][A-Za-z0-9\-]*`，不允许空格
- 任何无效输入均输出精确错误信息：`Invalid input. Try again.`

### 3. 菜单功能与交互设计

```
Campus Resource Management System
1. Add Resource
2. Remove Resource
3. Borrow Resource
4. Return Resource
5. Display All Resources
6. Filter by Availability
7. Display Sorted by Name
8. Total Penalty for Owner
9. Exit
Enter your choice:
```

| 选项 | 功能 | 关键行为 |
|------|------|----------|
| **1** | 添加设备 | 无效输入时从类型提示重新询问（不返回主菜单） |
| **2** | 移除设备 | 仅允许移除未被借用的设备 |
| **3** | 借用设备 | 标记为已借用，拒绝重复借用或不存在 ID |
| **4** | 归还设备 | 计算逾期罚款：`days × penaltyPerDay()`，0 天输出 `No penalty.` |
| **5** | 展示全部 | 按插入顺序输出，格式：`[Type] ID:XXXX Name:YYY Owner:ZZZ Available:Yes/No` |
| **6** | 按可用性筛选 | 输入 1 显示可借用，0 显示已借用 |
| **7** | 按名称排序 | 字母顺序排序展示，**不改变内部存储顺序**（通过临时指针向量实现） |
| **8** | 所有者罚款合计 | 汇总该所有者当前所有已借用设备的日罚款率总和 |
| **9** | 退出 | 干净退出程序 |

### 4. 现代 C++ 特性实践

| 特性 | 应用场景 | 代码示例 |
|------|----------|----------|
| **智能指针** | 资源对象生命周期管理 | `std::vector<std::unique_ptr<Resource>> resources;` |
| **Lambda 表达式** | 按 ID 查找资源 | `std::find_if(resources.begin(), resources.end(), [&id](const auto& r) { return r->getID() == id; });` |
| **STL 算法** | 按名称排序展示（不修改原容器） | `std::sort(tmp.begin(), tmp.end(), [](const Resource* a, const Resource* b) { return a->getName() < b->getName(); });` |
| **移动语义** | 插入新资源时避免拷贝 | `resources.push_back(std::make_unique<Laptop>(id, name, owner));` |

### 5. 封装与数据隐藏

- 所有数据成员设为 `private` 或 `protected`
- 通过公共 getter/setter 访问状态
- 非修改成员函数标记 `const`
