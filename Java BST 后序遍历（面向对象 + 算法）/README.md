# 二叉搜索树构造与后序遍历（Binary Search Tree Insertion & Post-order Traversal）

一个纯 Java 实现的二叉搜索树（BST）算法，从标准输入读取整数序列，构建 BST 后输出后序遍历结果。项目严格遵循面向对象编程范式，注重代码规范、时间效率与内存安全，通过自动化评测系统验证。

## 项目概述

本项目实现 BST 的核心插入算法与后序遍历，输入为一组逗号分隔的整数，输出为每个节点占一行的后序遍历序列。项目强调 OOP 设计原则的应用，包括封装、抽象、模块化与适当的错误处理，同时优化时间复杂度以通过性能分位评测。

## 技术栈

- **语言**：Java（JDK 8+）
- **编译**：`javac -encoding UTF-8 -sourcepath . BST.java`
- **运行**：`java -Dfile.encoding=UTF-8 -XX:+UseSerialGC -Xss64m -Xms1920m -Xmx1920m BST < Input.txt > Output.txt`
- **输入方式**：标准输入（`System.in`）
- **输出方式**：标准输出（`System.out`）

## 核心功能

### 1. 标准输入读取
- 从 `System.in` 读取逗号分隔的整数序列
- 解析输入字符串并转换为整数数组
- 处理可能的空行、换行符差异（`\n` / `\r\n`）

### 2. BST 插入算法
- 逐个将整数插入二叉搜索树
- 保持 BST 性质：左子树 < 根 < 右子树
- 时间复杂度：平均 O(n log n)，最坏 O(n²)

### 3. 后序遍历输出
- 左子树 → 右子树 → 根节点
- 每个节点值独占一行输出

### 4. 面向对象设计
严格遵循 OOP 核心原则：

| 原则 | 实现 |
|------|------|
| **封装** | 节点数据私有，通过 getter/setter 访问 |
| **抽象** | 树操作接口与实现分离 |
| **模块化** | 独立类负责输入解析、树构建、遍历输出 |
| **组合** | 节点通过引用关联形成树结构 |
| **消息传递** | 通过方法调用实现对象间协作 |

## 关键约束与注意事项

- **单文件提交**：所有类必须位于 `BST.java` 中
- **仅主类 public**：`public class BST` 包含 `main` 方法
- **无 package 声明**：使用默认包
- **仅标准库**：仅导入 `java.*` 包，禁止第三方依赖
- **内存限制**：2GB 沙箱环境（含 JVM 运行时）
- **时间限制**：5 秒超时
- **输出精确**：禁止多余空行，最后输出紧跟输入最后一行
