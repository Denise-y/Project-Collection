# 自定义图书馆管理系统（Custom Library System）

一个基于组合逻辑电路设计的 16 位图书馆管理系统，使用硬件描述语言（HDL）实现。该系统支持图书信息的寄存器加载、RAM 存储、自动价值计算、顺序读取及累加求和等完整功能。

## 项目概述

本项目设计并实现了一个完整的图书馆数据管理系统，通过数字逻辑电路模拟图书库存管理的核心流程。系统采用 16 位数据总线处理图书信息，支持最多 8 条图书记录的存储与运算。

## 核心功能

### 1. 寄存器数据加载
- 通过 `load` 信号将 16 位图书 ID（`inBookID`）、数量（`inBookNum`）和价格（`inBookPri`）加载至系统寄存器
- 实时输出加载的数据，并自动计算总价值（`outTotalVal = inBookNum × inBookPri`）

### 2. RAM 数据存储
- 通过 `store` 信号将寄存器中的数据写入指定 RAM 地址（3 位地址线，支持 0-7 共 8 个存储位置）
- 支持同时存储图书 ID、数量、价格三条独立数据
- 读取时根据地址输出对应存储位置的图书信息

### 3. 自动价值计算
- 在存储数据时自动执行 16 位乘法运算：`inBookNum × inBookPri`
- 计算结果作为 `outTotalVal` 与图书信息一并存入 RAM
- 示例：数量 3 × 价格 99 = 总价值 297

### 4. 顺序读取功能
- 通过 8 个独立开关（`load0` - `load7`）控制从对应 RAM 地址加载数据到寄存器
- 支持按地址顺序或随机访问已存储的图书记录
- 输出当前选中地址的完整图书信息及预计算的总价值

### 5. 总价值累加
- 顺序遍历 RAM 中的所有有效记录
- 累加每条记录的 `inBookNum × inBookPri` 结果
- 输出所有图书的总价值，同时显示最后访问的图书记录详情

## 技术实现

- **硬件描述语言**：HDL（Hardware Description Language）
- **数据位宽**：16 位数据总线，3 位地址总线
- **存储容量**：8 组图书信息（ID / 数量 / 价格 / 总价值）
- **运算单元**：16 位乘法器、累加器
- **主控文件**：`CW.hdl`

## 输入输出接口

| 信号 | 位宽 | 说明 |
|------|------|------|
| `inBookID` | 16-bit | 输入图书 ID |
| `inBookNum` | 16-bit | 输入图书数量 |
| `inBookPri` | 16-bit | 输入图书单价 |
| `load` | 1-bit | 加载数据到寄存器 |
| `store` | 1-bit | 存储数据到 RAM |
| `address` | 3-bit | RAM 存储/读取地址 |
| `load0-7` | 1-bit × 8 | 从对应 RAM 地址加载数据 |
| `outBookID` | 16-bit | 输出图书 ID |
| `outBookNum` | 16-bit | 输出图书数量 |
| `outBookPri` | 16-bit | 输出图书单价 |
| `outTotalVal` | 16-bit | 输出总价值 |

## 使用示例

以存储 3 本图书为例：

| 地址 | 图书 ID | 数量 | 单价 | 总价值 |
|------|---------|------|------|--------|
| 0 | 10001 | 3 | 29 | 87 |
| 1 | 10002 | 5 | 19 | 95 |
| 2 | 10003 | 2 | 99 | 198 |

- 设置 `load=1`，依次输入各图书信息
- 设置 `store=1` 并指定 `address`，将数据写入 RAM
- 系统会自动计算并存储 `数量 × 单价`
- 切换 `load0` - `load7` 可读取任意地址数据
- 顺序加载所有记录后，`outTotalVal` 输出总价值 380

## 技术亮点

- 实现了从**数据输入 → 寄存器缓存 → RAM 持久化 → 自动运算 → 顺序读取 → 批量求和**的完整数据流
- 通过组合逻辑电路实现 16 位算术运算（乘法、累加）
- 模块化的 HDL 设计，各功能芯片可独立测试与复用
