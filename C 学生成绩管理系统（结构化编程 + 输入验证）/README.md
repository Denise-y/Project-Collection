# 学生成绩管理系统（Student Grades Management System）

一个基于 C99 标准的交互式菜单驱动程序，实现完整的学生成绩录入、查询与管理功能。系统在参考实现的基础上进行了全面的输入验证与错误处理升级，能够优雅应对各种非法输入场景而不崩溃。

## 项目概述

本项目重新设计并实现了一个学生成绩管理系统，核心挑战在于在不改变原有功能的前提下，增强系统的鲁棒性。程序通过严格的输入校验机制，确保姓名唯一性、成绩范围合法性以及格式规范性，同时提供友好的重新输入流程，避免用户因一次错误输入而被迫重启程序。

## 技术栈

- 语言：C (C99 标准)
- 编译器：GCC（在 Linux 服务器 `cs-linux` 上验证通过）
- 编译命令：`gcc -std=c99 -lm student_grades.c -o student_grade`
- 标准库：仅使用标准 C 头文件，无外部依赖

## 核心功能

### 1. 交互式菜单系统
- 提供清晰的文本菜单界面，支持增删改查等操作
- 用户通过数字选项导航，操作完成后返回主菜单
- 界面行为与参考可执行文件完全一致

### 2. 严格的输入验证体系

 校验项  规则  错误处理 
------------------------
 姓名唯一性  新输入姓名不可与已有学生重复  提示重复，要求重新输入 
 成绩范围  必须在 [0, 100] 闭区间内  提示越界，要求重新输入 
 姓名格式  首字符和末字符必须为英文字母  提示格式错误，要求重新输入 
 姓名长度  最多 20 个字符（含空格）  截断或提示重新输入 
 菜单选择  必须为有效数字选项  防止非数字字符导致崩溃 

### 3. 容错重输入机制
- 任何非法输入触发静默重新输入提示，不显示错误信息
- 用户无需重启程序，直接在当前步骤重新输入即可
- 防止缓冲区溢出、段错误等导致程序崩溃

### 4. 数据管理
- 支持最多 50 名学生的信息存储
- 每条记录包含：学生姓名、对应成绩
- 支持成绩的增、删、查、改及列表展示

## 输入验证细节

### 姓名校验
```
有效示例 Alice Smith, Bob, Anne-Marie
无效示例 123Alice, Alice ,  Alice, A (首尾非字母)
```

### 成绩校验
```
有效范围 0, 50, 100
无效范围 -1, 101, 999
```

### 菜单选择保护
- 使用字符级读取替代 `scanf` 的默认数字解析
- 过滤非数字字符，防止输入 abc 导致缓冲区混乱或程序崩溃

## 关键实现亮点

- 防御性编程：所有用户输入点均设置校验关卡，假设用户可能输入任何内容
- 缓冲区安全：谨慎处理字符输入，避免残留换行符干扰后续读取
- 字符串处理：手动验证首末字符为字母，控制长度不超过 20 字符
- 状态管理：维护学生数组的状态一致性，确保删除修改操作后数据完整
- 零警告编译：代码通过 `-Wall -Wextra` 级别检查，无编译器警告
