# "In-the-Wild Bean" 咖啡忠诚度系统需求分析与设计（Coffee Loyalty System - Requirements & Design）

一个面向本地咖啡店的数字化客户忠诚度管理系统的完整需求分析与早期设计项目。项目涵盖用户需求的文本分析、UML 用例建模、系统流程设计以及移动端低 fidelity 原型，展示从客户沟通到设计交付的软件工程全流程。

## 项目概述

本项目为 "In-the-Wild Bean" 咖啡店设计一套数字化忠诚度管理系统，替代现有的纸质打孔卡方案。系统需支持多角色（咖啡师、顾客、经理、营销人员）的差异化需求，实现积分追踪、奖励兑换、个性化营销和数据驱动决策。项目严格遵循软件工程规范，产出可供客户会议直接展示的需求文档与设计原型。

## 技术栈

- **需求分析**：文本分析、用例建模、角色定义
- **UML 工具**：用例图（Use Case Diagram）、活动图/序列图（Activity/Sequence Diagram）
- **原型设计**：低 fidelity 原型（PowerPoint / 手绘 / 原型软件）
- **文档格式**：Markdown（嵌入图片）
- **版本管理**：Git 仓库 + Tag 标记

## Part A: 用户需求分析

### 业务背景

"In-the-Wild Bean" 目前使用**纸质打孔卡系统**，存在以下痛点：
- 顾客易丢失卡片，无法追踪进度
- 员工手动打孔和计算奖励，易出错且拖慢服务
- 缺乏顾客偏好和消费数据，无法精准营销

### 目标系统愿景

| 利益相关者 | 需求 |
|------------|------|
| **咖啡师** | 快速识别顾客、记录消费、自动更新积分、与 POS 系统无缝集成 |
| **顾客** | 移动应用注册、查看积分余额、浏览奖励、追踪交易历史、接收个性化优惠 |
| **经理 (Jonathan)** | 配置积分规则、生成运营报告（注册用户数、积分累积/兑换率、热门奖励）|
| **营销人员** | 按消费历史/积分余额细分顾客、创建定向营销活动、推送促销通知 |

### 非功能性需求

- **易用性**：界面直观，咖啡师无需大量培训
- **可扩展性**：随顾客增长处理更大数据量和用户流量
- **安全性**：数据加密、安全认证，保护顾客个人信息

### 交付物

1. **文本需求分析**
   - 识别所有参与者（Actors）
   - 提取并描述用例（Use Cases）
   - 包含备注、疑问（向客户提出的问题）、假设和推理依据

2. **用例图（Use Case Diagram）**
   - 展示参与者与用例的关系
   - 用例之间的包含（include）/扩展（extend）关系

3. **三个用户画像（Personas）**
   - 代表典型用户类型
   - 包含背景、目标、痛点、行为特征

## Part B: 系统需求与设计

### 设计前提

客户 Jonathan 认可初步需求理解，希望看到**高阶设计概念**（非类/对象级别），重点展示：
- 系统外观与交互方式
- 用户在不同用例间的导航流程

> **关键约束**：移动应用界面**绝不能像电子表格或微信群笔记**，应呈现为专业系统风格。

### 交付物

1. **活动图或序列图（Activity / Sequence Diagram）**
   - 基于一个核心用例
   - 展示系统内部流程与交互

2. **低 Fidelity 原型（Low-Fi Prototype）**
   - 选取一个**有意义的用例**进行原型设计
   - 工具可选：原型软件、PowerPoint、平板手绘、纸质原型（需数字化）
   - 展示界面布局、导航流程、关键交互

### 设计评估标准

| 维度 | 说明 |
|------|------|
| **选择理由** | 为何选用特定图表类型？包含备注、细节、问题和假设 |
| **理解深度** | 客户能否理解图表组件、关系及整体含义 |
| **图表间整合** | 不同图表间的一致性（如用例与原型中的相同利益相关者）|
