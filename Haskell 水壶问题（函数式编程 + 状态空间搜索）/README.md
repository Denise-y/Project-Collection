# 水壶问题状态空间搜索（Water Jug Problem - State-Space Search）

一个纯 Haskell 实现的经典 AI 水壶问题求解器，使用状态空间搜索技术寻找从初始状态到目标状态的最短操作序列。项目严格遵循函数式编程范式，以不可变数据结构和递归为核心，展示声明式编程在搜索问题中的优雅表达。

## 项目概述

本项目解决经典的"两个水壶量水"问题：给定容量分别为 X 升和 Y 升的两个无刻度水壶，通过填充、倒空、互相倾倒三种操作，精确量出 Z 升水。项目使用广度优先搜索（BFS）遍历状态空间，返回所有可行解路径并识别最短路径。

## 技术栈

- **语言**：Haskell（纯函数式编程）
- **核心概念**：不可变状态、递归、高阶函数、模式匹配、惰性求值
- **算法**：状态空间搜索 / BFS（隐式或显式实现）
- **文件**：`Water.hs`（单文件提交）

## 核心功能

### 1. 状态表示
- 每个状态为二元组 `(a, b)`：
  - `a` = 第一个水壶当前水量
  - `b` = 第二个水壶当前水量
- 初始状态：`(0, 0)`（两壶皆空）
- 目标状态：`(a, b)` 其中 `a == Z` 或 `b == Z`

### 2. 允许操作
| 操作 | 效果 |
|------|------|
| **Fill X** | 将第一个水壶装满至容量 X |
| **Fill Y** | 将第二个水壶装满至容量 Y |
| **Empty X** | 倒空第一个水壶 |
| **Empty Y** | 倒空第二个水壶 |
| **Pour X→Y** | 从第一个壶倒入第二个，直到 X 空或 Y 满 |
| **Pour Y→X** | 从第二个壶倒入第一个，直到 Y 空或 X 满 |

### 3. 搜索算法
- 从 `(0, 0)` 出发，BFS 遍历所有可达状态
- 避免重复访问已探索状态（防止循环）
- 收集所有到达目标状态的路径

### 4. 结果封装
返回三元组 `(path, is_shortest, path_length)`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `path` | `[(Int, Int)]` | 状态序列，如 `[(0,0),(4,0),(1,3)...]` |
| `is_shortest` | `Bool` | 是否为最短路径 |
| `path_length` | `Int` | 路径步数（状态数 - 1）|

### 5. 主函数接口
```haskell
solutionPath :: (Int, Int) -> (Int, Int) -> (Int, Int) -> ([(Int, Int)], Bool, Int)
-- solutionPath (capacityX, capacityY) (initialX, initialY) (targetX, targetY)
```

## 示例

**用 4L 和 3L 水壶量出 2L：**

```haskell
solutionPath (4, 3) (0, 0) (2, 0)
```

**输出：**
```haskell
([(0,0),(4,0),(1,3),(1,0),(0,1),(4,1),(2,3),(2,0)], False, 7)
```

**路径解读：**
1. `(0,0)` → 初始状态
2. `(4,0)` → Fill 4L
3. `(1,3)` → Pour 4→3（4L壶剩1，3L壶满）
4. `(1,0)` → Empty 3L
5. `(0,1)` → Pour 4→3（把1L倒入3L壶）
6. `(4,1)` → Fill 4L
7. `(2,3)` → Pour 4→3（4L壶倒满3L壶，自身剩2）
8. `(2,0)` → Empty 3L，4L壶有2L ✓

## 关键约束

- **显式类型声明**：每个函数必须声明类型签名
- **无副作用**：纯函数，无 IO Monad 滥用
- **简洁性**：避免冗长重复代码，利用 Haskell 表达力
- **正确数据结构**：状态为元组，路径为列表，结果为三元组

## 函数式编程亮点

- **不可变性**：状态转换生成新元组，无副作用
- **递归**：自然表达状态空间的深度/广度探索
- **模式匹配**：清晰解构状态与操作
- **高阶函数**：`map`、`filter`、`fold` 处理路径集合
- **惰性求值**：可能用于无限状态空间的按需探索

## 项目特点

- **纯函数式**：零可变状态，零副作用，数学级可推导性
- **声明式表达**：描述"是什么"而非"怎么做"
- **类型安全**：Haskell 强类型系统编译期捕获错误
- **算法经典**：状态空间搜索的函数式范式实现
- **代码简洁**：利用 Haskell 特性，数十行完成复杂搜索逻辑
