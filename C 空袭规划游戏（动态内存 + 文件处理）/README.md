# 空袭规划游戏（Airstrike Planner Game）

一个基于 C99 标准的交互式菜单驱动游戏，模拟军事空袭任务的目标管理、搜索、规划与执行流程。项目包含完整的源代码实现与一份不超过 500 字的技术报告，涵盖文件验证、目标判定、距离计算及内存泄漏检测等核心设计决策。

## 项目概述

本项目从零实现了一个空袭规划器游戏，完整复刻了参考程序的所有功能，并在其基础上进行了全面的输入验证与错误处理增强。玩家可以读取目标文件、搜索特定目标、规划空袭路线并执行打击任务。项目特别注重数据结构的合理设计、动态内存的安全管理以及模块化代码架构。

## 技术栈

- **语言**：C (C99 标准)
- **编译器**：GCC（在 Linux 服务器 `cs-linux` 上验证通过）
- **编译命令**：`gcc -std=c99 -lm airstrikeplanner.c -o airstrikeplanner`
- **标准库**：仅使用标准 C 头文件，无外部依赖
- **内存管理**：动态内存分配（malloc/free），附带泄漏检测

## 核心功能

### 1. 目标文件读取与验证
- 从外部文件加载空袭目标数据
- **文件有效性校验**：检查文件格式、数据完整性及一致性
- 无效文件被拒绝并提示用户，程序不崩溃

### 2. 目标搜索
- 支持按多种条件检索目标（如名称、坐标、类型等）
- 搜索结果精确展示，支持边界值处理

### 3. 空袭规划
- 选择多个目标制定打击计划
- **目标有效性判定**：验证目标是否符合打击条件（如距离、优先级等）
- 计算目标之间的**最小距离**，优化打击顺序与路径

### 4. 空袭执行
- 模拟执行已规划的空袭任务
- 状态更新与结果反馈

### 5. 交互式菜单
- 清晰的文本菜单导航，支持循环操作
- 用户界面与参考可执行文件完全一致

## 技术报告要点

报告（`report.pdf`，≤500 字）详细阐述了以下设计决策：

| 问题 | 解决方案概述 |
|------|-------------|
| **目标文件有效性判定** | 定义文件格式规范，校验结构完整性、数据类型正确性及逻辑一致性 |
| **有效目标识别标准** | 设定坐标范围、属性完整性、重复性检查等判定规则 |
| **目标间最小距离计算** | 采用欧几里得距离公式，遍历所有目标对计算最小值 |
| **内存泄漏检测** | 使用 Valgrind 工具进行动态内存分析，确保所有 `malloc` 均有对应 `free` |

## 关键实现亮点

### 模块化设计
- 程序拆分为多个独立函数，每个函数职责单一
- 函数参数全部有效使用，返回值被正确消费
- 复杂数据使用 `struct` 结构体封装，避免全局变量滥用

### 动态内存安全
- 使用 `malloc`/`free` 管理目标数据数组
- 程序退出前释放所有已分配内存
- 通过 Valgrind 验证无内存泄漏

### 输入鲁棒性
- 处理典型有效输入、边界值及非法输入
- 文件读取失败、格式错误、数据越界等场景均不崩溃
- 菜单选择防非法字符输入

### 代码质量
- 零编译器警告（`-Wall -Wextra`）
- 一致的命名规范与缩进风格
- 关键逻辑配有详细注释
