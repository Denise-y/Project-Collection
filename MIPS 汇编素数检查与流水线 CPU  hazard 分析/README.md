# MIPS 汇编素数检查与流水线 CPU  hazard 分析（MIPS Prime Checker & Pipeline Hazard Analysis）

一个基于 MIPS 汇编语言的素数检测程序，结合 5 级流水线 CPU 的 hazard 识别与缓解策略分析。项目涵盖底层汇编编程、CPU 微架构理解以及计算机体系结构教学演示，展示从指令级编程到处理器设计的完整知识链条。

## 项目概述

本项目是 COMP1047: Systems and Architecture 课程 Part 2 的完整实现，分为两个核心部分：
- **Q1.a**：使用纯 MIPS 非伪指令实现素数检查与迭代求和
- **Q1.b**：基于 Q1.a 代码分析 5 级流水线 CPU 中的 hazard 并提出解决方案
- **Q2**：作为客座讲师准备计算机体系结构专题的 5 分钟教学演示

## 技术栈

- **汇编语言**：MIPS Assembly（仅使用非伪指令）
- **模拟器**：QtSpim
- **CPU 架构**：单周期 CPU → 5 级流水线 CPU（MIPS）
- **教学工具**：PPT + 口头演讲视频（mp4）
- **参考教材**：*Digital Design and Computer Architecture (2nd Edition)*, Chapter 7.5

## Part 1: MIPS 汇编编程（10 Marks）

### Q1.a — 素数检查器（8 Marks）

#### 功能要求
- 提示用户输入 1-100 范围内的整数 X
- 输入验证：范围检查，无效则重新提示
- 判断 X 是否为素数
- 若 X 为素数，迭代计算 1 到 X 的累加和并输出

#### 示例运行

**示例 1（素数）：**
```
Enter an integer (1 to 100): 7
7 is a prime number.
Sum from 1 to 7: 28
Thank you for using the program. Goodbye!
```

**示例 2（非素数 + 无效输入）：**
```
Enter an integer (1 to 100): -5
Error: Please enter a value between 1 and 100.
Enter an integer (1 to 100): 9
9 is not a prime number.
Thank you for using the program. Goodbye!
```

#### 关键约束

| 约束 | 说明 |
|------|------|
| **纯非伪指令** | 仅使用 MIPS 参考卡中的真实指令，禁止伪指令 |
| **循环迭代** | 使用 for/while 循环实现素数判定与累加求和 |
| **禁止查表** | 不得预存结果表，必须实时计算 |
| **效率优化** | 避免不必要的计算（如只需检查到 √X）|
| **输入鲁棒** | 循环提示直到获得有效输入 |

### Q1.b — 流水线 Hazard 分析（2 Marks）

#### 分析框架
基于 Q1.a 的 MIPS 代码，识别 **两个不同类型的 hazard**：

**Hazard 类型覆盖：**
- **数据相关（Data Hazard）**：RAW、WAR、WAW 依赖
- **控制相关（Control Hazard）**：分支/跳转指令导致流水线断流

#### 分析要求
1. **定位代码位置**：精确指出 Q1.a 中引发 hazard 的两处代码
2. **解释原因**：说明为何该位置在 5 级流水线中会产生问题
3. **提出解决方案**：软件（如插入 NOP、指令重排）或硬件（如前递、停顿）均可
4. **方案论证**：证明所提方案的有效性

#### 报告规范
- 格式：Markdown（≤500 字 + 最多 10 张图/表）
- 结构：清晰的章节标题、正确的术语、专业的图表引用
